# Trademark Policy

This policy covers the Open Ecosystem OS name, logos, icons, wordmarks, and other project
identity marks, whether registered or unregistered.

The software license lets you use, copy, modify, and distribute the software under its
terms. It does not grant permission to use project identity marks in a way that implies
endorsement, sponsorship, or official status.

## Permitted Uses

You may use the Open Ecosystem OS name to:

- truthfully refer to the original project
- describe compatibility with the project
- identify an unmodified copy of the project
- link to the project repository or documentation
- state that your work is based on or forked from the project

## Uses That Need Permission

Please get written permission before using project identity marks to:

- brand a modified distribution as Open Ecosystem OS
- imply official approval, sponsorship, or partnership
- use the project name or logo as the primary branding for a separate product or service
- register a domain, package, app, company, or social account that may be confused with
  the official project
- create a confusingly similar name, logo, or visual identity

## Forks and Modified Versions

Forks and modified versions should use a distinct name and visual identity. They may state
that they are based on Open Ecosystem OS, provided the statement is truthful and does not
imply endorsement.

Acceptable examples:

```txt
ExampleOS, a fork of Open Ecosystem OS
Built from Open Ecosystem OS
Compatible with Open Ecosystem OS
```

Avoid names or branding that make a modified version look like the official project.

## No Warranty

This policy is not legal advice. It may be updated as the project matures, especially if
formal logo assets, package names, hosted services, or registered marks are introduced.
