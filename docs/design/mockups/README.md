# Mockups

This folder contains exported visual references for Open Ecosystem OS screens.

## Rules

- Use lowercase kebab-case filenames.
- Prefer one image containing both desktop and mobile views when possible.
- Do not commit temporary names such as `imagegen.png`.
- If a mockup is added, moved, renamed, or replaced, update `docs/design/SCREEN_CATALOG.md`.
- Mockups are references, not pixel-perfect implementation contracts.

## Categories

- `public/`: marketing, docs, architecture, roadmap, case studies.
- `workspace/`: shared authenticated workspace surfaces.
- `apps/`: end-user applications.
- `platform/`: admin, operational, security, billing, migration.
- `developer/`: API, events, plugins, marketplace, community.
- `case-studies/`: public case-study pages.
- `flows/`: user journeys and system flowcharts.
