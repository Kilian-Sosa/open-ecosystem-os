# apps/web

Next.js frontend for Open Ecosystem OS.

Responsibilities:

- public portfolio
- authenticated workspace
- dashboard
- Drive UI
- Media/OCR UI
- Open Pages UI
- Open Ecosystem Flows UI
- admin/platform UI
- design system showcase

Initial setup command suggestion:

```bash
npx create-next-app@latest apps/web --typescript --tailwind --eslint --app --src-dir
```

Then add shadcn/ui and shared components.
